# Skills for claude.ai chats

Upload each zip at claude.ai → Settings → Capabilities → Skills → "Upload skill".
Once uploaded, they work in every chat (web, desktop, mobile).

| Zip | Source |
|---|---|
| ui-ux-pro-max.zip | github.com/nextlevelbuilder/ui-ux-pro-max-skill |
| frontend-design.zip | github.com/anthropics/skills (official Anthropic frontend-design) |
| app-store-screenshots.zip | github.com/ParthJadhav/app-store-screenshots |
| emil-design-eng.zip | github.com/emilkowalski/skill |
| color-palettes.zip | your two saved palettes (Deep Teal & Rust, Midnight Navy & Amber) |

The full set of skills (including all of Emil's animation skills) is also in `.claude/skills/`,
which Claude Code loads automatically in this repo.
